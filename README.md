# PEPR FrenchMinds neuropsychological test scoring

This repository contains the scoring algorithms for neuropsychological tests used in the **PEPR FrenchMinds project**.

## Objective

The primary goal of this project is to validate the scoring logic. We aim to ensure **100% correspondence** between the output generated by these scripts and the official scoring implemented within the **PEPR FrenchMinds platform** database.

## Repo structure

The repository is organized by test. Each test folder contains three files:

1.  **Scoring script (`.R`)**: An R script defining the scoring logic.
2.  **Input data**: A dataset containing fake raw participant data.
3.  **Expected output**: A dataset containing the data scored exactly as it should appear in the PEPR database.

## Available Tests

Currently, the following tests are implemented:

*   **ANT** (Attention Network Test)

## Usage

To validate the scoring for a specific test:
1. Pull the input-data file 
2. Score it with the FrenchMinds platform scoring
3. Compare the results against the expected-data file to confirm that the calculations match perfectly

If there is a mismatch, we need to correct the "error" (or different methodological decision) we used.
